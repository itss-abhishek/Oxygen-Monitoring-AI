Hardware Layer Integration (Future)

OxySense includes a built-in hardware abstraction layer. When your ESP32 microcontroller is ready:

  1. Configure the ESP32 to connect to hospital Wi-Fi.
  2. Flash the firmware to send HTTP POST to:
    http://<server-ip>:5000/api/telemetry
  3. Send JSON payload with pressure_bar and flow_lpm.
  4. The dashboard will automatically switch from DEMO MODE to LIVE HARDWARE.
