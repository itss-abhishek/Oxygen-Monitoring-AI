About This Project

Personalized Healthcare Recommendation System: IoT-Enabled Smart Oxygen Cylinder Monitoring

🎓 Project Scope

Developed as a Third-year B.Tech Major Project to solve critical oxygen supply visibility challenges during patient transport, ICU surge demands, and ward management.

Built with Python, Flask, vanilla JavaScript, Chart.js, and Lucide icons. Designed with a modular hardware abstraction layer ready for immediate ESP32 wiring.

⚠️ Clinical Disclaimer

This software prototype is engineered strictly for academic demonstration. All telemetry is simulated. Clinical oxygen titration must only be administered by licensed medical practitioners.

Hardware Layer Integration (Future)

OxySense includes a built-in hardware abstraction layer. When your ESP32 microcontroller is ready:

  1. Configure the ESP32 to connect to hospital Wi-Fi.
  2. Flash the firmware to send HTTP POST to:
    http://<server-ip>:5000/api/telemetry
  3. Send JSON payload with pressure_bar and flow_lpm.
  4. The dashboard will automatically switch from DEMO MODE to LIVE HARDWARE.
